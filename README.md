# Test registry

A copy of the live registry.5stack.gg index plus the `ea-adverts` entry, for testing on our panel before the entry is proposed to 5stackgg/plugin-registry. It is a snapshot: upstream plugin releases published after `generated_at` are not in it. Rebuild with `python3 -I build.py ../5stack/ea-adverts.json` after fetching `upstream.json`.
